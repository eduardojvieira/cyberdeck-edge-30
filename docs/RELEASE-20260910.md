## Imagen frente al teléfono

La imagen reúne los **fixes del sistema/port** de la tabla, no todas las
instalaciones personales. Homebrew, entornos científicos, editores y agentes
continúan disponibles en el celular; sus fuentes/launchers/configuración portable
se documentan para reinstalación selectiva. No se exportan tokens, claves, cookies,
historial, sesiones, Wi-Fi, backups, bases Engram ni plugins privados.

Se conserva el boot H29 binario exacto. Kernel dpkg puede mostrar etiqueta
histórica `eqsdev1`; no afirmar que el builder kernel actual produce bytes H29
ni reinstalar el paquete para arreglar esa etiqueta. `inputs.json` es el contrato
del binario. No se promete build desde un clon sin sus inputs/firmware local,
ni reproducibilidad byte a byte de ext4/UUID/ZIP.

La imagen tiene PIN de plantilla y no LUKS: cambiar PIN antes de conectar redes;
no es una daily de trabajo. El arranque/rescate previo está probado por separado;
la instalación limpia nueva y el comportamiento de todo el conjunto aún necesitan HIL.
